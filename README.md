# Cpp-Learning

This repository contains exercises and examples I write while learning C++ independently.

My goal is to strengthen my understanding of C++, learn how memory works, and gradually build more complex programs.

## Topics

- Data types and operators
- Functions
- Pointers and references
- Arrays and strings
- Memory management
- Classes and objects
- Templates and STL

## Exercises

- Calculating the sum of positive elements
- Swapping values using references and pointers
- Finding the first positive element
- Counting positive elements using pointers
- Reversing an array using two pointers

## Tools

- Language: C++
- Editor: Visual Studio Code
- Compiler: GCC (`g++`)
- Version control: Git and GitHub

## Building and Running

Each `.cpp` file is a separate program with its own `main()` function. Compile each file individually.

From a terminal opened in the source file's directory:

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic reverse_array.cpp -o reverse_array.exe
```

Run in Windows PowerShell:

```powershell
.\reverse_array.exe
```

Replace `reverse_array.cpp` with the actual filename of the program you want to compile.
